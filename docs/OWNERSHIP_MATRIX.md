# Ownership matrix — drift, secrets, storage, logging, state and monitoring

Status: documentation inventory derived from the Terraform configuration at main
`7172d25` on 10 November 2026. This page is not live proof. No AWS read, `terraform
plan`, `terraform apply`, deployment or drill was performed for it, and it does not
change any resource. Every review date and recommended default is a proposal that the
accountable owner must ratify.

The matrix exists to close the documentation half of INF-001 ("resolve intended
egress, logging, storage, state locking and monitoring settings; document ownership
between Terraform and deploy CI") and the ownership half of OPS-001. It replaces no
runbook step: detection, rollback, restore and rotation procedures remain in
[INCIDENT_RECOVERY_RUNBOOK.md](INCIDENT_RECOVERY_RUNBOOK.md).

## How to read the owner and mechanism columns

| Term             | Meaning in this matrix                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Terraform        | HCL in this repository is the intended owner. A normal `plan` should show no drift.                                                                           |
| Deploy CI        | A GitHub Actions workflow in the backend or frontend repository writes the live value after Terraform creates the resource.                                   |
| Console/rotation | A human operator or AWS-managed rotation writes the live value; Terraform deliberately does not reconcile it.                                                 |
| Role             | The accountable role from the runbook: platform, backend, data/privacy, security, email, frontend or on-call owner. Roles are not yet mapped to named people. |

Evidence means the smallest reproducible artefact that would prove the stated
ownership. Common evidence is a reviewed `terraform plan` for the affected resource, a
read-only AWS CLI response, a release artefact hash, or a signed drill record. **No
evidence row below has been collected for this change.**

Review dates are aligned to the Trivy exception expiry (`2027-03-31`) except for the
owner decisions, which are proposed for `2026-12-31` because they block other work.
